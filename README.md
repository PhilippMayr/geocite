# GEOcite

GEOcite is a scientometric project for extracting bibliographic references from historical geoscience publications and analyzing scholarly communication over time.

The project aims to support the longitudinal monitoring of scientific communication by making historical citation data accessible for research and analysis.

## Gold Standard

The `annotations/` folder contains the gold-standard annotations used for evaluating and validating the extraction of bibliographic references.

## Project

GEOcite was developed as part of a research project funded by the German Research Foundation (DFG), in collaboration with the University of Passau.
